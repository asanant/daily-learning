📱 Android 面试题（5题）

1. Activity 的生命周期方法有哪些？

A. onCreate, onStart, onResume
B. onCreate, onStart, onResume, onPause, onStop, onDestroy
C. onCreate, onResume, onDestroy
D. onStart, onResume, onPause
✅ 答案：B
Activity 完整生命周期：onCreate() → onStart() → onResume() → onPause() → onStop() → onDestroy()。还有 onRestart() 在 Activity 从停止状态重新启动时调用。

2. Fragment 和 Activity 的区别是什么？

A. Fragment 不能有自己的布局
B. Fragment 必须嵌入 Activity 中使用
C. Fragment 比 Activity 运行更快
D. Activity 不能包含 Fragment
✅ 答案：B
Fragment 不能独立存在，必须嵌入到 Activity 中。Fragment 是模块化的 UI 组件，可以在多个 Activity 中复用，支持动态添加、移除和替换。

3. SharedPreferences 是线程安全的吗？

A. 完全线程安全
B. 完全不安全
C. 读操作安全，写操作不安全
D. 只有 commit() 是安全的
✅ 答案：A
SharedPreferences 本身是线程安全的（内存中操作），但跨进程不安全。commit() 同步写入磁盘，apply() 异步写入。推荐使用 apply() 避免 ANR。

4. Handler、Looper、MessageQueue 的关系？

A. 三者没有关系
B. Handler 发送消息到 MessageQueue，Looper 循环取出消息
C. Looper 直接处理消息
D. MessageQueue 创建 Handler
✅ 答案：B
Handler 发送 Message 到 MessageQueue，Looper.loop() 无限循环从 MessageQueue 取出消息，分发给对应的 Handler 处理。每个线程只能有一个 Looper。

5. ANR 是什么？如何避免？

A. ANR 是网络超时
B. ANR 是应用无响应（Application Not Responding）
C. ANR 是内存溢出
D. ANR 是编译错误
✅ 答案：B
ANR = Application Not Responding。触发条件：主线程 5 秒内无响应（Activity）或 BroadcastReceiver 10 秒内未完成。避免方法：耗时操作放子线程、使用协程、避免主线程 I/O。
